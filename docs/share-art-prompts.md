# Agy Lens 像素素材出图稿 · 横版街机版

Flow 按角色、决斗场、小镇、徽章、特效分项目。每次提交「下方固定画风段 + 一条对应类别的素材正文」，将正文中的尖括号换成具体条目。数量 x1，每批含失败最多六张，逐张核对后再继续。

## 全项目固定画风段 · v1 · 角色画风与比例已通过

```text
Agy Lens 的世界是一座仍在运转的幻想工坊，采用九十年代二维街机手绘像素画法。按目标尺寸落笔，轮廓由整齐的像素台阶构成。先把主体归成一个能认出的剪影，再用相连的暗面、固有色、受光面三档切出体积。暗面往靛青偏，左上受光面稍暖。布料以宽折面转折，旧铜只在棱角留窄亮边，玻璃用一段断开的硬亮线。选一个最值得看清的形状，把最强的局部明暗反差留给它。其余细节并入大色块。保留干净的负形与硬边；排除渐变光晕、平滑抗锯齿、均匀撒点的纹理。
```

**哪些固定，哪些可换。** 各职业和场地可换主色、材质、道具与环境光色。暗部的冷色倾向、明暗分组、材质画法和像素边缘全项目共用。把职业或地点写成一个在小尺寸下仍成立的外形特征。例如炼金术士的斜药具带连到胯侧试剂套，骑士的窄盾越过前肘，观星台的偏心铜环切开夜空。每一项只选与题材有关的材料。

| 类别 | 同一画法如何落到素材上 |
|---|---|
| 格斗角色与 VS 图 | 以炼金术士第三稿可见的头身关系和占幅为标尺，平视、侧向对手。先读姿态和招牌装备，再读脸和衣褶。站姿的脚底、手与道具的遮挡都要讲得通。 |
| 动作 | 附该职业已批准母版。继承色块面积、装备、光向与描边，只改关节和随动部分。单状态四格横排。 |
| 决斗场 | 采用 skill 的横向侧视三层构图。远景合并大色面、中景用一个地标交代地点、近景给双方一条连续水平地面。最亮的背景点避开头手。 |
| 小镇与拆件 | 采用 skill 的斜俯视场景构图。屋顶与南墙分成两档明度，地块与独立道具沿用整景的视角、光向和像素尺度。 |
| 徽章与特效 | 徽章在 24×24 用一个实物轮廓讲清梗，亮点标出关键缺口或接触处。特效沿动作方向画实色像素簇，逐帧改变面积。 |

**看样与定稿。** 首次核对用已有决斗场、候选角色和一枚徽章按实际显示尺寸并排看，不为拼样启动批量生成。先看角色能否从背景里读出、职业轮廓能否辨认、徽章缩小后梗是否成立。通过后把版本号与已批准样本一并记在本节。个别素材的穿模、裁脚、视角错误只修该项正文。跨类别都出现同一问题时再修固定段并升版。角色基准为[已批准的炼金术士第三稿](../art-src/characters/alchemist/original-late.webp)。后续职业以成图的头身关系、手脚尺度、像素密度和明暗分组为准；体格和职业装备可变。炼金术士动作仅挂第三稿。场景和徽章的同屏效果另审。

**规范来源。** pixel-art-prompt-optimizer 提供原生尺度、硬边与透明边缘规则；其 Game Art Prompt Kit 中的 parallax-sideview-arcade-environment、angled-topdown-pixel-scene、reference-based-sideview-action-sheet 分别用于舞台、小镇和角色动作。game-character-sprites 提供母版、单方向连续帧、脚底锚点和缩小验收方法。幻想工坊、冷暗暖亮与材质笔法是本项目的美术选择。 三项已安装为项目级技能：`.claude/skills/pixel-art-prompt`、`.claude/skills/game-art-prompt-kit`、`.claude/skills/game-character-sprites`。

已通过的最新角色母版包括 [05 新手第二稿](../art-src/characters/novice/original-late.webp) 和 [11 玻璃吹制师第二稿](../art-src/characters/glassblower/original-late.webp)。后续改龄与动作以对应原图为参考。

## 动作 · 每个状态各交一张横条

### Flow 单角色待机 GIF

提示词按 `game-character-sprites` 的角色母版、单动作、单方向、全身轮廓、硬像素边缘及纯色底约束编写。该 skill 的原始模板用于分帧横条，默认待机四帧。Flow GIF 沿用项目的四拍动作设计，在时间上连续播放。骑士采用已验证的竖版全身起始帧与洋红底，四帧横条规格用于下一节的静态素材。

骑士待机提示词：

```text
以附件中定稿的后期骑士为起始帧。单人全身，保持参考图朝右的站姿、头身比与像素大小。保留灰胡须、象牙白肩甲、深蓝罩袍、前臂盾和斜背入鞘长剑。镜头平视固定。连续播放一个待机循环：戒备站定，膝盖轻屈，抬胸吸气，呼气回落衔接起始姿势。两只靴底始终落在原处，盾随前臂微动，剑鞘贴着背带。每一刻都看得到头顶、剑柄、盾沿、鞘尾和靴底，四周留有纯 #FF00FF 空间。轮廓清晰，像素硬边，有限色阶。背景均匀纯色，无地面、投影、文字或边框。
```

```text

```
