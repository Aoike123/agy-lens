# 分享卡片像素素材工作流

[横版街机素材提示词](share-art-prompts.md)是当前 Flow 出图入口。先审缓存炼金术士的全身侧面战姿，再与狂战士放进午夜观星台核对。十二座决斗场各画一张完整背景；研究所小镇另用斜俯视构图。角色动作与 VS 图附上本轮已验收的职业母版。

## 生成与验收

午夜观星台的骑士与盐路刀舞者同屏构图、点阵字和分段血条已通过。后续对战审稿沿用此版站位与 HUD。[通过的同屏稿](../art-review/handoff/observatory-knight-dancer-hud.png) · [透明 HUD](../art-review/handoff/observatory-duel-hud.png)

- 每次提交一张，等待出图并核对，再提交下一张。每批含失败最多六张。页面卡住时先检查进行中的任务，必要时自动刷新一次，再按项目记录核对结果，避免重复提交。Flow 报告异常活动时暂停提交。
- 主图和 VS 立绘都需要全身。验收时沿轮廓检查头顶、双脚、武器或道具末端，以及四边留白。缩到目标尺寸后再看一次。
- 每个状态用一套独立连续图，统一四帧横排、从左到右。固定机位和比例，检查脚底基线、服装、惯用手、装备及动作方向。待机和行走要检查首尾衔接。
- 决斗场在同一条交手线上放置双方检查遮挡。小镇地块铺满画布，道具保留纯洋红底或透明通道。徽章在 24×24 下检查辨识度。

## 目录结构

| 位置 | 入库 | 内容 |
|---|---|---|
| `art-src/roster.json` | 是 | 角色、阶段、待机名称、决斗场清单和网格常量 |
| `art-src/characters/<职业>/` | 是 | `starter-male`／`starter-female`／`mid`／`late` 的 100×100 PNG；`idle-<阶段>.webp` 为 192×128、24 帧/秒透明待机；`original-<阶段>.webp` 为 512×512 定稿原图 |
| `art-src/arenas/<场景>.webp` | 是 | 1376×768 决斗场 |
| `art-raw/` | 否 | Flow 原片 MP4、抠像中间件、720×1280 定位板、作废文件；`art-raw/inbox/` 放待着色的平铺生成图 |
| `art-review/` | 否 | 审稿图、落选稿、`normalize-growth.py` 生成的对照页 |

运行 `npm run art` 按 `roster.json` 核对 `art-src/`：每个职业阶段的精灵尺寸、待机尺寸与帧数、决斗场是否齐全，以及有无清单外的文件。`node scripts/share-art/build.mjs --shade` 把 `art-raw/inbox/` 里按提示词标题命名的平铺生成图（如 `char-alchemist-attack@4.png`）送进着色图层，结果和对照预览写到 `art-out/`。

Python 工具依赖见 `scripts/share-art/requirements.txt`；`import-idle-mp4.py` 另需 ffmpeg。

## 着色图层做了什么（`scripts/share-art/shade.mjs`）

| 阶段 | 作用 |
|---|---|
| 抠背景 | 有透明通道就用透明通道；否则取边框最常见颜色当键色，从边缘泛洪抠除（封闭区域里同色的部分保留），再去掉一圈溢色。 |
| 对齐像素网格 | 人物和道具裁到主体后按原生尺寸逐块取样，每块中间 70% 的像素按调色板投票取色，避开生图工具在块边缘的模糊混色；同一序列共用缩放比例。透明图层保持整幅宽度（可平铺），按锚点裁切高度。 |
| 锁定调色板 | 所有素材共用 17 条 × 9 级色阶（`RAMP_DEFS` × `RAMP_STEPS`），暗部偏蓝紫、亮部偏暖黄。 |
| 清理 | 合并极少用的颜色，去掉孤立像素和针孔，清理轮廓上的背景溢色。 |
| 选择性描边 | 轮廓取所贴材质色阶的最暗级：背光侧（下、右）最暗级，受光侧（上、左）次暗级。已有黑描边就原地重新着色，没有就外扩 1 像素。特效不描边。 |
| 光照 | 启用重新打光时，统一光源左上：上、左内缘提亮一级，右上内缘加边缘光，下内缘和脚底压暗一级。特效不重新打光。 |
| 背景与图块 | 逐块取 OKLab 均值锁到调色板；背景在同一色阶相邻两级间做 4×4 有序抖动，图块不抖动。 |

素材尺寸与处理方式见 `scripts/share-art/build.mjs` 的 `NAMED_SPECS` 和 `ASSET_SPECS`；场景拼合坐标见同文件的 `SCENES`，会随素材一起写进 `share-assets.js`。

## 角色成长形态

所有角色从共用新手起步，进入对应职业的中期形态，再成长为该职业的后期形态。初期有男性和女性两款新手形象。两款都使用蓝工服、木尺与工具包，以 05 新手第二稿的 512 像素画布为标尺，统一输出 100×100 透明 PNG。[新手对照](../art-review/handoff/starter-review.png) · [初期素材](../art-src/characters/novice/)

女性新手定稿为第七稿，单马尾自然下垂，一手握住肩上的木尺，另一手扶住胯边工具包。后续动作以此稿为角色参考。[女性新手母版](../art-src/characters/novice/original-starter-female.webp)

海港潜水匠为男性，成长顺序为男性新手 → 海港潜水匠中期 → 海港潜水匠后期。

12 个职业各有一张中期与一张后期形象。中期以同一职业的后期原图作编辑参考，改变体态、年龄感与装备，同时保留眉鼻、惯用手与职业配色。[后期总览](../art-review/handoff/final-form-100.png) · [炼金术士中期与后期对照](../art-review/handoff/alchemist-growth-review-03.png)

炼金术士年轻过渡期第三稿已通过。其余 11 位的年轻过渡期已逐张生成，待审。使用 scripts/share-art/normalize-growth.py 从原图重建 100×100 PNG：先在高分辨率的键色边界消除洋红溢色，再采样到新手网格并复查内外轮廓。[全部角色素材](../art-src/characters/) · [对照第一页](../art-review/handoff/transition-review-1.png) · [对照第二页](../art-review/handoff/transition-review-2.png)
