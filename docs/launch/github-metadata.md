## Release & GitHub polish checklist

1. Refresh all screenshots & sanitized fixtures after UI changes:
   ```bash
   node scripts/render-screenshots.mjs
   ```
2. Verify unit suite + release ZIP smoke build:
   ```bash
   node --test tests/*.mjs
   node scripts/build-release.mjs
   ```
3. Bump `plugin.json`, `package.json`, `sidecars/agy-lens/package.json`, move `[Unreleased]` into `## [x.y.z] - YYYY-MM-DD` in `CHANGELOG.md`, commit, tag, and push:
   ```bash
   git push -u origin main
   git tag vX.Y.Z
   git push origin vX.Y.Z
   ```
4. Pushing tag `vX.Y.Z` triggers `.github/workflows/release.yml`, which builds and attaches `agy-lens.zip`, `agy-lens-vX.Y.Z.zip`, `SHA256SUMS.txt`, and changelog-backed release notes with `docs/img/hero-en.png`.
5. Update GitHub **About** description, Website URL, Topics, and re-upload `docs/img/social-preview.png` whenever screenshots refresh.
6. Pin a `Roadmap & feedback` issue (or enable GitHub Discussions) inviting Antigravity users to share quota pool layouts, custom models, and favorite share card themes.
