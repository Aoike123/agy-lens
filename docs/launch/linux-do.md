佬友们好，重度用 Antigravity 2.0 时最近踩了两个很隐蔽的坑：

1. **周额度「懒启动」陷阱**：池子刷新满 100% 后，只要你不发第一条消息，7 天倒计时根本不开始算（白白拖晚下一次刷新）；
2. **看不清套餐到底值不值**：过去 4 个周期总共 400% 的周额度，到底用掉了多少、白白过期浪费了多少、每周 100% 额度到底有没有暗中缩水、哪个项目开子智能体烧得最狠——客户端里全都没有。

所以我把之前开源的本地侧边栏插件 **Agy Lens** 一口气升级到了 **v2.8.0**（纯内置 Node.js 24，0 依赖、不用 Python）：

### 这次最实用的几个能力
- **额度闭环 + 防浪费（额度页）**：
  - 实时读取各池官方 5h / 每周额度与倒计时；刷新待激活时明确提示 `首次使用后开始倒计时`。
  - 新增 **可选单池「自动唤醒」开关**（默认严格关闭，开启前 0 调用）：打开后一旦该池刷新满额未倒计时，自动用池内最便宜的模型发 1 条禁工具极短消息启动周期并删除临时对话（实测仅耗 ~0.00085% 周额度，带单周期持久化熔断锁 + 12h 冷却，杜绝重复消耗）。
  - 周期估值柱图下方直接汇总 **`已用 / 总可用` · `本周期剩余` · `往期未用`**（如 4 周期 `400%` 中浪费了多少一目了然），点击任意周期柱子还能展开**周期内分段消耗速度下钻**与并发对话数。
- **按项目归类 + 分段锁定周额度（历史页）**：
  - 汇总桌面端 + CLI 全量历史，支持按项目分组/筛选、多级子智能体树自动归集，以及旧对话被清理后的自动归档；跨周期项目严格按当时各期单价分段累加 `≈ 周额度 X%`。
- **6 种分享卡片 + 像素 RPG 角色卡 + 实况/动图导出**（评论区晒图神器）：
  - 内置 5 款 60fps WebGL 艺术海报（高山·年鉴 / 深海·潜航 / 星穹·日晷 / 瑞士·叠印 / 磷光·丝带）+ **像素·角色卡**（根据你的真实用量算出 13 种职业、6 维 RPG 属性与 12 项成就），全系支持深浅双主题。
  - 全屏无黑边预览，一键导出或复制 **实况照片（`.jpg`）/ MP4 / WebM / GIF / 2× PNG / SVG**，绝不读取任何对话标题或本地路径。
- **面板内一键升级**：后续版本在顶部横幅直接点「立即更新」，自动校验 `SHA256SUMS.txt` 原地升级。

### 30 秒安装

**Windows（PowerShell）：**

```powershell
irm https://raw.githubusercontent.com/Aoike123/agy-lens/main/scripts/install.ps1 | iex
```

**macOS / Linux：**

```bash
curl -fsSL https://raw.githubusercontent.com/Aoike123/agy-lens/main/scripts/install.sh | bash
```

装完重启 Antigravity，在 `Customizations → Installed` 开启 **Agy Lens** 即可；也支持终端直接跑 `npx github:Aoike123/agy-lens`。
